PSYCH 302 / 305 · Introduction to Computational Methods in Psychology
University of Alberta · Fall 2026 · Wednesday 18:00–21:00

This course teaches computing tools used in psychological research: a GitHub repository, Visual Studio Code on your laptop, version control, a data file, and a written report. The examples are ordinary psychology. Simple Syllabus is the official outline (weights, late work, letter grades). Canvas is the gradebook and the assignments. The handbook is the laboratory site.

Each week

  1. Open that week’s module below. It links the laboratory page and the Canvas report.
  2. Work in your private repo kylemath/psych302-305-YOURUSERNAME in VS Code on your laptop. Each week’s report is README.md in that week’s folder. Setup: workflow.html.
  3. Push, then paste on Canvas. Weekly reports are due the Tuesday after class, 17:00.

Assessment

  • 50% weekly laboratory reports (weeks 1–9; drop the lowest)
  • 15% midterm project plan (28 October)
  • 35% final project and 3-minute in-class talk (2 December). Not a written exam.

Weekly marking: rubrics. Midterm and final: project page. Official late work and letter grades: Simple Syllabus (same for 302 and 305).
